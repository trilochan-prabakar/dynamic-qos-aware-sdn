# Dynamic QoS-Aware Path Selection Using SDN

## Project Overview
This project implements a Quality of Service (QoS)-aware path selection system using Software-Defined Networking (SDN).

## Objectives
- Evaluate network paths using QoS metrics.
- Monitor network performance, including latency, jitter, bandwidth, and packet loss where implemented.
- Select suitable paths based on a QoS scoring mechanism.
- Investigate dynamic rerouting when network conditions change.

## Technologies Used
- Python
- Ryu SDN Controller
- Mininet
- Open vSwitch
- OpenFlow

## Project Files
- `qos_controller.py` — SDN controller and path-selection logic.
- `topology.py` — Network topology definition.
- `requirements.txt` — Python dependencies.
- `work_report.pdf` — Project implementation and experimental results.
